# gigafin

Personal finance manager: Go, SQLite (modernc), sqlc, goose, htmx 4 + html/template UI,
public JSON API generated by ogen. Module `github.com/ysomad/gigafin`.

## Commands
- `make tools` — download tool deps (sqlc, goose, ogen are `tool` directives in go.mod, run via `go tool`).
- `make generate` — regenerate sqlc and ogen code after editing `queries/`, `migrations/` or `api/public.yaml`.
- `make test` — unit tests (`go test -race ./...`); DB tests use temp-file SQLite in-process.
- `make lint` — golangci-lint.
- `make build` / `make run` — build `bin/gigafin`; `run` also migrates `$(DB)` (default `gigafin.db`) and serves on `$(ADDR)`.
  Make builds with tag `apidocs` (embeds Scalar API docs); `run`/`dev` serve them (`HTTP_API_DOCS=true`). Plain `go build` leaves them out.
- `make user-add login=NAME [role=admin] [p=PASS]` / `make user-passwd login=NAME [p=PASS]` / `make user-role login=NAME role=user|admin` — manage users (add and passwd prompt for the password unless `p` is given); `admin` may download backups.
- `make migrate-create name=NAME` — the only way to create a migration; then write both Up and Down.
- `make migrate-up` / `make migrate-down` / `make migrate-status` — apply, roll back one, show status for `$(DB)`.

## Code Style
Follow [CODE_STYLE.md](CODE_STYLE.md) for all Go code.

## Rules
- Do not run the app or any database yourself. The user does it.
- Do not start any containers (docker, docker compose, testcontainers).
- No thin helper wrappers around a few lines or a single call. Write the code inline where it
  is needed; a little repetition beats indirection.
- Storage is dumb: no DEFAULTs, CHECK constraints, enums or other validation in migrations.
  Defaults, validation and enum values live in Go code only.

## Repository Navigation (CRITICAL)
This project is indexed using `gograph`. **DO NOT use `grep` or `cat` for structural Go code analysis.**

1. Before answering architecture or repository questions, inspect the available `gograph_*` MCP tools for the current project and use the server registered for that repository.
2. The MCP server builds and refreshes an in-memory AST graph automatically. If MCP tools are unavailable, run `gograph build .` in the terminal, then use CLI commands such as `gograph implementers <InterfaceName>`.
3. For compilable, build-selected packages, `gograph build . --precise` adds type-checked CHA/SSA enrichment. Add `--tags=integration` when tagged files/tests belong to the graph, and use the same option on `gograph mcp` startup so refreshes retain the selection. CHA is conservative, and a failed retry retains an already-fresh successful precise artifact for the same sources instead of replacing it with a fallback.
4. To extract a function body or mock stub without reading the whole file, use the source tool.
5. Use targeted text search for string literals, ordinary non-sensitive configuration, generated or non-indexed files, and documentation. Do not inspect `.env`, key, certificate, kubeconfig, tfstate, or credential files unless the user explicitly places them in scope.
